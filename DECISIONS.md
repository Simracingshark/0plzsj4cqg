# Решения

## 2026-11-11 Форма: PWA на GitHub Pages + сборщик в GitHub Actions
Причина: бесплатно, работает без ПК пользователя, на телефоне ставится иконкой, без магазинов приложений.
Отвергнуто: нативная апка (сборка/публикация ради личного инструмента), сборщик на ПК (цены стоят, пока ПК выключен), свой VPS (нет).

## 2026-11-11 Публичное репо со случайным именем `0plzsj4cqg`
Пользователь согласен на публичное. В репо только код и публичные цены; город и прочие настройки живут в localStorage телефона, в репо не попадают. Коммиты с noreply email GitHub.

## 2026-11-11 Источники: всё, включая Prom/Bigl
Hotline как основа, плюс профильные магазины напрямую, Rozetka, Allo, Prom/Bigl. Шум Prom фильтровать. ek.ua пропущен: Cloudflare 403.

## 2026-11-11 Hotline: только открытые данные списка
Цены по отдельным магазинам Hotline намеренно прячет (фальшивые цены в скрытых span, настоящие собираются скриптом). Обходить защиту не стали. Берём из списка: мин–макс цену, число предложений, материал, вес. Конкретные магазины парсим напрямую.
Hotline включает капчу после нескольких сотен запросов с одного IP: пауза 4 с между страницами, не чаще раза в 11.5 ч (`every_h` в shops.json), при капче — ошибка источника и прошлые данные.

## 2026-11-11 Сборщик на stdlib, без зависимостей
regex по HTML + schema.org ld+json. Нет pip install в Actions, быстро стартует. Минус: хрупко к смене вёрстки; один упавший источник не роняет остальные.

## 2026-11-11 Только 1.75 мм
По выбору пользователя. Позиции с 2.85/3 мм в названии отбрасываются; где диаметр не указан — оставляем.

## 2026-11-11 Интерфейс на украинском
По просьбе пользователя. Код и комментарии — по-русски.

## 2026-11-11 Город и доставка — настройки в приложении
Пользователь вписывает сам. Тариф Новой Почты не зашит: стоимость доставки по умолчанию вводится вручную (по умолчанию 0), есть порог бесплатной доставки.

## 2026-11-11 История цены: точка только при изменении
`history.json` растёт медленно: новая точка при изменении цены или наличия, в пределах дня — перезапись.
