# Решения

## 2026-11-11 Форма: PWA на GitHub Pages + сборщик в GitHub Actions
Причина: бесплатно, работает без ПК пользователя, на телефоне ставится иконкой, без магазинов приложений.
Отвергнуто: нативная апка (сборка/публикация ради личного инструмента), сборщик на ПК (цены стоят, пока ПК выключен), свой VPS (нет).

## 2026-11-11 Публичное репо со случайным именем `0plzsj4cqg`
Пользователь согласен на публичное. В репо только код и публичные цены; город и прочие настройки живут в localStorage телефона, в репо не попадают. Коммиты с noreply email GitHub.

## 2026-11-11 Источники: всё, включая Prom/Bigl
Hotline как основа (сразу много магазинов), плюс профильные магазины напрямую, Rozetka, Allo, Prom/Bigl. Шум Prom фильтровать (рейтинг продавца, наличие). ek.ua пропущен: Cloudflare 403.
