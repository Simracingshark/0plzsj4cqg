# Решения

## 2026-11-11 Форма: PWA на GitHub Pages + сборщик в GitHub Actions
Причина: бесплатно, работает без ПК пользователя, на телефоне ставится иконкой, без магазинов приложений.
Отвергнуто: нативная апка (сборка/публикация ради личного инструмента), сборщик на ПК (цены стоят, пока ПК выключен), свой VPS (нет).

## 2026-11-11 Публичное репо со случайным именем `0plzsj4cqg`
Пользователь согласен на публичное. В репо только код и публичные цены; город и прочие настройки живут в localStorage телефона, в репо не попадают. Коммиты с noreply email GitHub.

## 2026-11-11 Источники: всё, включая Prom/Bigl
Hotline как основа, плюс профильные магазины напрямую, Rozetka, Allo, Prom/Bigl. Шум Prom фильтровать. ek.ua пропущен: Cloudflare 403.

## 2026-11-11 Hotline: только открытые данные списка
Цены по отдельным магазинам Hotline намеренно прячет (фальшивые цены в скрытых span, настоящие собираются скриптом). Обходить защиту не стали. Берём из списка: мин–макс цену, число предложений, материал, вес. Конкретные магазины парсим напрямую.
Hotline включает капчу после нескольких сотен запросов с одного IP: пауза 4 с между страницами, не чаще раза в 11.5 ч (`every_h` в shops.json), при капче — ошибка источника и прошлые данные.

## 2026-11-11 Сборщик на stdlib, без зависимостей
regex по HTML + schema.org ld+json. Нет pip install в Actions, быстро стартует. Минус: хрупко к смене вёрстки; один упавший источник не роняет остальные.

## 2026-11-11 Только 1.75 мм
По выбору пользователя. Позиции с 2.85/3 мм в названии отбрасываются; где диаметр не указан — оставляем.

## 2026-11-11 Интерфейс на украинском
По просьбе пользователя. Код и комментарии — по-русски.

## 2026-11-11 Город и доставка — настройки в приложении
Пользователь вписывает сам. Тариф Новой Почты не зашит: стоимость доставки по умолчанию вводится вручную (по умолчанию 0), есть порог бесплатной доставки.

## 2026-11-11 История цены: точка только при изменении
`history.json` растёт медленно: новая точка при изменении цены или наличия, в пределах дня — перезапись.

## 2026-11-11 Общие парсеры по движкам вместо модуля на каждый магазин
WooCommerce Store API, Shopify products.json, ld+json в списках и универсальный `cards` (маркер карточки в shops.json). Новый магазин чаще всего — одна строка конфига. Отвергнуто: отдельный модуль на каждый сайт (много кода), headless-браузер (тяжело для Actions).

## 2026-11-11 de-filament.com.ua — только как список магазинов
Это уже существующий агрегатор. Его данные не парсим, берём только идеи, какие магазины добавить, и парсим сами магазины.

## 2026-11-11 Bambu Lab без веса = 1 кг (оценка)
Официальные катушки Bambu — 1 кг, но в названиях часто не пишут. Ставим `weight_est`, в UI «≈ … (оцінка)». Наборы, Support и PVA не трогаем.

## 2026-11-11 Без картинок в данных
Картинки удваивали offers.json. В UI вместо фото — кружок цвета.

## 2026-11-11 Prom — через поиск, а не категорию
Страница 2+ категории Prom без JS отдаёт ту же первую страницу; поиск `/ua/search?search_term=..&page=N` листается честно. 10 фраз по материалам × 5 страниц, раз в 11.5 ч. Продавец пишется в `seller`.

## 2026-11-11 Tucans убран, Polydream не подключён
Tucans отвечает 403 и из GitHub Actions — защиту не обходим. У Polydream цены грузятся скриптом; headless-браузер в Actions пока не тащим.

## 2026-11-11 Картинки — ссылкой на магазин, катушки на главной — свой SVG
В данных только адрес превью (`image`), грузится с сайта магазина (`referrerpolicy=no-referrer`, при ошибке остаётся кружок цвета). Плитки материалов рисуют SVG-катушку в цвет материала: одинаково, легко, не зависит от чужих фото.

## 2026-11-11 Склейка товаров — только точное совпадение
Ключ: бренд + материал + вес + набор значимых слов названия (без «пластик», «для 3D-принтера» и т.п.). Разные написания одного товара не склеятся, зато разные цвета не смешаются. Отвергнуто: склейка по нормализованному цвету — «Зелений» покрывает army green/olive/хакі.

## «Перехідний» пластик не показываем (2026-11-11)
Катушки «перехідний колір / Transitioning» — цвет непредсказуемый, на фото коллаж всех цветов, пользователь не понял, что это, и попросил так не делать. Они же сбивали «дешевле медианы» (самые дешёвые). Отвергнуто: оставить с пометкой. «Уцінка» без перехода оставляем.
