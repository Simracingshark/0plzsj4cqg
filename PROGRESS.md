# Прогресс

## Сделано (2026-11-11)
- Сборщик: Hotline (каталог), 3DDevice (OpenCart), PlastFill на Prom. Нормализация материала/бренда/цвета/веса, ₴/кг, фильтр смол/принтеров/ручек/2.85 мм.
- PWA на украинском: список с фильтрами и избранным, «Найкраще за кг», карточка с графиком истории, калькуляторы (деталь по граммам, цена за кг, сравнение с доставкой), настройки (город, доставка, порог бесплатной).
- GitHub Actions: cron каждые 6 ч, коммит данных, деплой на Pages. Pages включён (build_type workflow).
- Проверено локально на 375 px: без горизонтального скролла, карточка, график (на тестовых точках), калькуляторы.
